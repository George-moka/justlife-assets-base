The loop

One sentence in. A real screen out.

The same three stages run every time — and they're fast enough to iterate on in the room, during a review.

1

You describe it

Plain English, the way you'd brief a teammate. No component names to memorize.

"a salon list with filters, ratings and service cards"
2

Claude plans it

The model picks the right DS components and fills them with realistic content — returned as a strict screen spec.

{ component: "Service Card", props: { price: "149" } }
3

It renders live

Each node maps to a real React DS component. Photos and icons resolve from the asset CDN. What you see is the system.

→ live, prop-driven, token-accurate screen
Why it's trustworthy

It speaks the design system, not "close enough".

Every screen is built from the real tokens and components — so what a stakeholder sees is what engineering can ship.

01 Live, prop-driven components +
Not screenshots. Each block is a real React component with the same props as Figma — state, cta, selected — so variants behave exactly like the system.
02 Exact tokens, light on white +
Brand #00C3FF, cards on background/secondary over a white screen, the real radius and spacing scale. No invented colors.
03 The Dirham mark — never "AED" text +
Prices render the Dirham vector and strip any currency words the model adds, so you never get a doubled "₯ AED 149". Try the toggle on the right.
04 73 components catalogued, growing +
The full Component/cards inventory ships as a catalog. 28 are pixel-faithful today; the rest render as labeled DS cards until they're built — so a screen never breaks.

Under the hood

Serverless, by design.

No backend to babysit. Three pieces, each doing one job. Tap a node for detail.

STORAGE

GitHub + jsDelivr

The asset library — photos, 2D & 3D icons, the manifest and the DS catalog.
A public repo served on a global CDN. The app resolves each asset id to a cached URL. Free, fast, no server.
→
RUNTIME

Netlify + Function

Hosts the app and runs one serverless function that securely talks to Claude.
The browser only calls /api/generate. The function attaches the secret API key — which never reaches the browser.
→
INTELLIGENCE

Claude API

Turns the prompt — plus the component catalog — into a structured screen spec.
Strict JSON in, strict JSON out. The catalog keeps it on-system; the rules keep prices numeric and screens coherent.
Iterate, don't restart

Edit the screen you have.
